      How PhishLens decides

      Seven real stages. Every result comes from an implemented check; anything that cannot run is shown as Not Available, never as clean.

      1–2 · URL checks

      Validation, normalization and structure: length, keywords, IP hosts, @ tricks, shorteners, brand look-alikes, homographs.

      3–4 · Domain & DNS

      TLD, domain age (RDAP), DNS records, resolved IP scope and a TLS handshake to inspect the HTTPS certificate.

      5 · Threat intelligence

      VirusTotal detections and Google Safe Browsing matches — the only sources that can mark a URL confirmed malicious.

      6–7 · Risk & report

      A 0–100 score without double counting correlated clues, a verdict, and an explanation for every finding.
